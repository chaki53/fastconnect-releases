## 📦 Скачать

> **Не знаете какой файл выбрать?** Качайте `arm64-v8a` — подходит для 95% современных телефонов (любой Android 2019 года и новее).

| Файл | Для каких устройств | Размер |
|---|---|---|
| 🟢 **`FastConnect_X.X.X_arm64-v8a.apk`** | **Современные телефоны (рекомендуется)** | ~29 МБ |
| `FastConnect_X.X.X_armeabi-v7a.apk` | Старые телефоны (до 2018 г.) | ~29 МБ |
| `FastConnect_X.X.X_universal.apk` | Универсальный (если не знаете) | ~63 МБ |
| `FastConnect_X.X.X_x86_64.apk` | Эмуляторы / планшеты Intel | ~30 МБ |
| `FastConnect_X.X.X_x86.apk` | Старые Intel-устройства | ~30 МБ |

### Установка
1. Откройте APK на телефоне → разрешите установку из неизвестных источников
2. Войдите через Telegram или Email
3. Готово — нажимайте «Подключиться»

> 💡 Автообновления работают **прямо из приложения**. Однажды установив FastConnect, новую версию ставить вручную не нужно.

## ❓ FAQ

<details>
<summary><b>Какой APK выбрать?</b></summary>

В 95% случаев — `arm64-v8a`. Если телефон старее 2018 года или не уверены — берите `universal`, он работает на всём (но больше весит).
</details>

<details>
<summary><b>Android просит «разрешить установку из неизвестных источников»</b></summary>

Это нормально — мы пока не публикуемся в Google Play. Разрешите установку в настройках, поставьте APK, потом можно выключить обратно.
</details>

<details>
<summary><b>Безопасно ли это?</b></summary>

Да. APK подписан одним и тем же ключом, обновления приходят только из этого репозитория. Чувствительные данные (CVV, полные номера карт, пароли) **никогда** не хранятся ни на устройстве, ни на сервере.
</details>

<details>
<summary><b>Не подключается, что делать?</b></summary>

1. Нажмите «Обновить серверы» в аккаунте
2. Попробуйте сменить страну в списке серверов
3. Проверьте, не исчерпан ли лимит устройств (Аккаунт → Устройства)
4. Напишите в поддержку прямо из приложения

</details>

<details>
<summary><b>Где найти мою реферальную ссылку?</b></summary>

Аккаунт → «Пригласить друга». Там две ссылки: для Telegram-бота и для прямой установки приложения.
</details>
